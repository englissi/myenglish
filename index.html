🔐 Gemini API 키 보안 금고 (GitHub 노출 방지)

소스코드에 키를 적지 않고 브라우저 로컬 금고에 암호화 저장하여 계속 사용합니다

🛡️ 왜 이렇게 저장하나요? (GitHub Secret Scanning 차단 100% 예방)

코드 파일 안에 API 키를 직접 적어 GitHub에 올리면 자동 스캐너가 감지해 키를 즉시 정지시킵니다. 아래 입력창에 한 번만 입력해 두시면 내 기기 브라우저(LocalStorage)에만 난독화·암호화되어 영구 보관되므로 GitHub에 코드를 그대로 올려도 절대 노출되지 않고 안전하게 계속 쓸 수 있습니다.

키를 입력하고 [금고에 저장하고 계속 사용하기]를 누르면 책 목차 사진 업로드 시 실제 Gemini Vision AI가 이미지 속 글자를 읽어 단원을 자동 추출합니다.
